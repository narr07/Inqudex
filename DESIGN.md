# Inqudex: Design Guidelines

Desktop utility for SEO professionals and web administrators managing indexing, site audits, search console analytics, and organic traffic simulation.

## Identity
- Product name: Inqudex
- Brand initials: `IN`
- Visual motif: Clean ruler tick accents under page headers.

## Palette
- Neutral base: warm stone (light `#F6F4EF`, dark `#171614`).
- Core: deep dark `#1F2A24` for sidebar and primary headings.
- Accent: signal orange for primary actions and active navigation indicators.
- Semantic: standard green/amber/red indicators for latency and status chips.

## Typography
- Main font: Bricolage Grotesque Variable (bundled offline).
- Monospace: System terminal font for live logs and telemetry.

## Layout & Components
- 6px radius on controls and tables, 10px on cards.
- Clean flat cards with subtle border separators.
- Phosphor icons (`@iconify-json/ph`).
